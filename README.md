# Save the date – Ida & Fritjof

En liten responsiv GitHub Pages-sida med ett kuvert som öppnas när besökaren trycker på det. Kortet glider upp ur kuvertet.

## Publicera med GitHub Pages

1. Skapa ett nytt repository på GitHub.
2. Ladda upp `index.html` och mappen `assets`.
3. Öppna **Settings → Pages** i repositoryt.
4. Under **Build and deployment**, välj **Deploy from a branch**.
5. Välj `main` och `/ (root)`, och tryck **Save**.
6. Efter någon minut finns sidan på `https://ditt-användarnamn.github.io/repository-namn/`.

## Ändra texten

Öppna `index.html` och sök efter:
- `Ida & Fritjof`
- `Lördagen den 4 september 2027`
- `Åsa Herrgård, Lammhult`

Byt texten direkt i HTML-filen. Byt bilden genom att ersätta `assets/herrgard-watercolor.jpg` med en egen bild med samma filnamn.

Sidan använder vanlig HTML, CSS och JavaScript – inga ramverk eller installationer behövs.
